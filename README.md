# بوت Wolf Proxy لإدارة البروكسيات تلقائياً — نسخة متعددة القنوات + زاحف ذكي + مولد

أي مستخدم يقدر يضيف البوت أدمن في قناته الخاصة، والبوت بيسجلها على حسابه تلقائياً
وبيديرها له بالكامل بالأزرار من غير أي تدخل من صاحب البوت.

## هيكل المشروع
```
proxybot/
├── config.py     ← التوكن والمصادر وإعدادات عامة (بدون قناة ثابتة)
├── crawler.py    ← الزاحف الذكي: يكتشف مصادر بروكسي جديدة تلقائياً عبر GitHub Search API
├── generator.py  ← المولد: يجرب منافذ بديلة شائعة لنفس عناوين IP المكتشفة فعلاً فقط
├── engine.py     ← يجمع الزاحف + المولد + الفحص في تدفق واحد
├── scraper.py    ← جلب وتنقية البروكسيات من المصادر الثابتة والمكتشفة
├── checker.py    ← الفحص المتزامن (سرعة + دولة)
├── storage.py    ← قاعدة بيانات SQLite (قنوات متعددة، كل واحدة بمالكها وإعداداتها)
├── keyboards.py  ← أزرار التحكم
├── bot.py        ← البوت نفسه (نقطة التشغيل)
└── requirements.txt
```

## 1) التثبيت على VPS (Ubuntu)
```bash
sudo apt update && sudo apt install python3 python3-venv python3-pip -y

cd proxybot
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## 2) الإعدادات
افتح `config.py`:
- `BOT_TOKEN` → توكن البوت من @BotFather (أو حطه كمتغير بيئة `BOT_TOKEN`).
- `OWNER_IDS` → آيديات تقدر تدير كل القنوات المسجلة (مضاف بالفعل: 6812997550).
- `MAX_CHANNELS_PER_USER` → اختياري، حد أقصى لعدد القنوات لكل مستخدم (0 = بدون حد).
- `GITHUB_TOKEN` → اختياري (متغير بيئة)، يرفع حد الطلبات المسموح بها لـ GitHub Search API الخاص بالزاحف الذكي.

## 3) التشغيل الدائم (systemd)
```bash
sudo nano /etc/systemd/system/proxybot.service
```
```ini
[Unit]
Description=Wolf Proxy Bot
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/root/proxybot
ExecStart=/root/proxybot/venv/bin/python3 bot.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```
```bash
sudo systemctl daemon-reload
sudo systemctl enable proxybot
sudo systemctl start proxybot
journalctl -u proxybot -f
```

## 4) طريقة الاستخدام لأي شخص (بدون تدخلك)
1. يبدأ محادثة خاصة مع البوت ويبعت `/start`.
2. يضيف البوت **كمشرف (Admin)** في قناته، مع صلاحية "نشر الرسائل" على الأقل.
3. البوت يسجل القناة على حسابه فوراً ويبعتله تأكيد في الخاص.
4. يبعت `/start` تاني فتظهرله قناته، ويضغط عليها فتفتح لوحة تحكم كاملة:
   - 🚀 جلب وفحص الآن (بالزاحف الذكي + المولد + الفحص الحقيقي)
   - 📊 الإحصائيات
   - 🟢/🔴 تفعيل أو إيقاف التشغيل التلقائي
   - ⏱ ضبط الفاصل الزمني (1 - 24 ساعة)
   - 📁 تحميل آخر قائمة شغالة كملف
   - 🗑 إلغاء ربط القناة

## كيف يعمل الزاحف الذكي والمولد
- **الزاحف (crawler.py)**: يبحث تلقائياً عبر GitHub Search API عن مستودعات جديدة تحتوي ملفات
  `http.txt` / `socks4.txt` / `socks5.txt` وغيرها، ويضيفها كمصادر إضافية في كل دورة جلب —
  من غير الحاجة لتحديث `config.py` يدوياً.
- **المولد (generator.py)**: لكل IP ظهر فعلاً في نتائج الجلب، يجرب منافذ بديلة شائعة
  (80, 8080, 3128, 1080...) على نفس الـ IP فقط، ثم يمررها للفحص الحقيقي — بدون أي مسح
  عشوائي لعناوين خارج نطاق المصادر الفعلية.
- **engine.py** يربط الثلاثة في تدفق واحد: اكتشاف مصادر → جلب → توليد مرشحين → فحص فعلي.

## ملاحظات مهمة
- كل قناة مستقلة تماماً بإحصائياتها وفاصلها الزمني الخاص.
- لو البوت اتشال من القناة أو فقد صلاحية الأدمن، بتتوقف القناة تلقائياً من قاعدة البيانات.
- فحص SOCKS4/5 بيعتمد على مكتبة `aiohttp_socks` المضمّنة في requirements.txt.
- لازم يبدأ المستخدم محادثة خاصة مع البوت (`/start`) قبل إضافته للقناة، عشان يقدر يستقبل رسائل التأكيد والتنبيهات.
